# Release Distribution Policy

This project supports public preview builds and private/local data imports. Keep
those two modes separate.

## Public Preview Builds

Public builds should ship the small packaged seed database generated by:

```bash
npm run db:prepare-package-db
```

The public package should not include the full imported LeetCode or 力扣 problem
catalog unless explicit distribution rights have been reviewed and documented.
The release verifier blocks packaged `seed.db` files that contain a large
third-party problem catalog by default.

Suggested personal-site wording:

```text
Algo Platform Preview Build

macOS Apple Silicon preview build is available for testing. This is an unsigned
educational preview package with a small demo problem set. Full LeetCode/力扣
imports are supported for personal local study, but the full third-party catalog
is not bundled in the public download.

Windows builds will be linked after Windows packaging has passed validation.
Algo Platform is not affiliated with LeetCode or 力扣.
```

## Private Local Imports

Developers can import from a local `leetcode-problemset` checkout:

```bash
npm run import:leetcode-cn -- --source /path/to/leetcode-problemset/leetcode-cn/originData
npm run db:materialize-samples -- --source LEETCODE
```

That flow is intended for local study, local demos, and development validation.
Do not publish the resulting `dev.db` or replace the public `seed.db` with it
for a public release unless rights have been cleared.

## Rights Review Override

If a future release has documented distribution rights for a full third-party
problem catalog, the release guard can be bypassed explicitly:

```bash
ALLOW_FULL_THIRD_PARTY_PROBLEMSET_RELEASE=1 npm run make
```

Only use this override after recording the source, license or permission basis,
and release scope. Attribution alone and "educational use" wording are not a
substitute for distribution permission.

## Platform Status

- macOS Apple Silicon: packaged and verified locally.
- Windows: Forge/Squirrel packaging is configured, but the artifact must be
  generated and opened on Windows before it is advertised as available.
- Intel Mac or universal macOS: not validated yet.
